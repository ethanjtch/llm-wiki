## 定义
Nous Research 的开源代理框架（仓库 `hermes-agent`），作者是 Teknium。它的特殊之处在于**用自己开发自己**：Teknium 日常使用 Hermes 处理该仓库的开发工作，代理在协作中记录有效做法、被纠正时更新自己的技能。

## 关键事实
- **规模**：2026 年 9 月，仓库有超过 100 万行非测试 Python；`gateway/run.py` 单文件 34,847 行。
- **自主重构（2026-09-02 → 09-04）**：一次 19 活跃小时的运行派出 1,393 个子代理（峰值 218 并发），非测试 Python 减少 34.4%（1,063,826 → 698,363 行），PR #102117 合并。模型花费约 $19.3k（含后续约 $25k，不含人工评审），人工估算 $150k–$1.8M。
- **形态**：技能（skills）是可读的 Markdown 文档，附参考文件与脚本，代理在工作时自行编写与修订；`/goal` 提供持续目标，让代理在本会停下时继续。
- **运行方式**：协调者运行在单台 i7 / 64GB 桌面机的一个 Python 进程里，工具走本地子进程，推理远程（Claude Fable 5.1）；工人以 git worktree 隔离。
- **署名作者**：Teknium（Nous Research）。
